# CoolSwiftApp

A sleek SwiftUI starter app named **Stellar Flow** with a gradient dashboard, ambient controls, and feature cards.

## Open in Xcode

1. Open Xcode.
2. Choose **File > Open...** and select the repository folder.
3. Pick an iOS or macOS simulator and run.

## What’s included

- A hero header with supporting copy.
- A glassy ambient control card with toggle and slider.
- A list of colorful feature cards for daily boosts.

## Customize it

- Update the gradient palette in `ContentView`.
- Add new cards in `Feature.sample`.
- Swap icon names using SF Symbols.
